# Approved design direction

The user chose The Pudding as the visual reference. This brief supersedes the prior Scroll-craft editorial experiment. Build a colorful visual news index leading into the complete unchanged bulletin. Avoid imitating proprietary illustrations or the reference brand. Preserve all original content and files outside deneme/. All cover text comes from actual bulletin JSON. No made-up figures or diagrams. Desktop has an asymmetric opening pair and smaller covers; phone has a vertical story collection. Motion is optional and never hides content. End with an invitation to return to the index and the original footer.
